# Velyr Lead Scan — So startest du es

## Jeden Lauf starten
Öffne Claude Code in diesem Ordner und gib folgenden Prompt:

Lies INSTRUCTIONS.md und queries.md in diesem Ordner und führe den
Velyr Lead Scan komplett durch. Schreibe das Ergebnis nach
leads-<heutiges Datum>.md wie in INSTRUCTIONS.md beschrieben.

## Wiederholter Gebrauch
Einfach denselben Prompt erneut ausführen, z.B. wöchentlich. Jeder Lauf
erzeugt eine neue, datierte Markdown-Datei — alte Läufe bleiben erhalten,
damit du siehst, wie sich das Themenfeld über Zeit entwickelt.

## Wenn etwas nicht funktioniert
- Reddit blockt (429): automatisch pausieren und erneut versuchen.
- X/Twitter Login-Wall: im gesteuerten Browser einmal manuell einloggen,
  dann erneut starten.
- IndieHackers liefert nichts: Google-Fallback (site:indiehackers.com)
  sollte greifen.

## Was das NICHT macht
Dieses Setup sammelt nur Links zum manuellen Durchgehen. Es schreibt keine
Antworten, schickt keine DMs, folgt niemandem automatisiert. Outreach bleibt
bei dir.
