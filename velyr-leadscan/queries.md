Plattform-Syntax es erfordert, z.B. Anführungszeichen bei Reddit/HN teils
ignoriert).

## Hinweise zur Nutzung
- Pro Cluster mindestens 2-3 Queries pro Plattform durchlaufen, nicht alle
  28 Queries auf jeder Plattform (zu viel Redundanz/Zeit) — stattdessen:
  HN + Reddit: alle Queries (günstig, schnell, API-basiert)
  IndieHackers + X: nur die 8-10 vielversprechendsten Queries (teurer,
  Browser-basiert, langsamer)
- Bei X ggf. Queries kürzen/vereinfachen (X-Suche reagiert oft besser auf
  2-4 Wörter als auf ganze Phrasen)
- Cluster E (Shopify) v.a. auf den Shopify-Subreddits (r/shopify, r/ecommerce,
  r/shopifyDev, r/Entrepreneur) + HN-/Reddit-Volltext laufen lassen. `shopify
  github theme sync` / `shopify store version control` zielen gezielt auf das
  schon-gesyncte Sub-Segment; die übrigen Shopify-Queries breit halten (jeder
  Store mit Conversion-/Theme-Schmerz zählt, der GitHub-Sync ist die
  Onboarding-Brücke, kein Suchfilter).
